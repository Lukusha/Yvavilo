# ყვავილო

ყვავილების ჩუქებისა და მნიშვნელოვანი თარიღების მართვის საპროტოტიპო ვებაპლიკაცია. შექმნილია Next.js-ით, React-ითა და TypeScript-ით.

## ადგილობრივად გაშვება

დააყენეთ დამოკიდებულებები ბრძანებით `pnpm install`, შემდეგ გაუშვით `pnpm dev`. გახსენით `http://localhost:3000`.

## როგორ მუშაობს დემო

- მთავარი გვერდი, ადამიანები, ყვავილების მაღაზია, თარიღები, შეტყობინებები, შეკვეთები და შეკვეთის ექვსსაფეხურიანი ფორმა ინტერაქტიულია.
- ადამიანები, თარიღები, შეტყობინებები და დემო შეკვეთები ინახება მხოლოდ ბრაუზერის მეხსიერებაში.
- შეკვეთის გაფორმებისას გადახდა და რეალური მიწოდება არ ხდება. შეკვეთებში ღილაკი „მიტანილად მონიშვნა“ ასახავს თაიგულს მიმღების პროფილსა და მთავარ გვერდზე.
- სიახლის მაჩვენებელი არის შეფასება ყვავილის ტიპისა და მიწოდებიდან გასული დღეების მიხედვით. აპლიკაცია ფიზიკურ თაიგულს ვერ აკვირდება.
- ბარათის ტექსტის შეთავაზებები წინასწარ დაწერილი მაგალითებია. AI სერვისი და სერვერული ავტორიზაცია ჯერ არ არის დამატებული.

დემოს მომხმარებელია ლუკა; მაგალითის მიმღებები არიან ანა, დედა და ნინო.
