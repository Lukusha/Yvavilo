# ყვავილო

ქართული ყვავილების საჩუქრების ვებაპი. Next.js ქმნის სტატიკურ ინტერფეისს, ხოლო Cloudflare Worker და D1 მართავს ანგარიშებსა და თითოეული მომხმარებლის მონაცემებს.

## რაც მუშაობს

- რეგისტრაცია, შესვლა, უსაფრთხო cookie სესია და პაროლის შეცვლა
- მომხმარებლების მონაცემების სრული გამიჯვნა
- ახლობლის დამატება და რედაქტირება, მათ შორის შეკუმშული პროფილის ფოტო, მისამართი, რჩეული ყვავილები, ფერები და შენიშვნები
- დაბადების დღე, წლისთავი და შეუზღუდავი დამატებითი მნიშვნელოვანი თარიღები
- პერსონალური დაფა, კალენდარი, შიდა შეხსენებები და `.ics` კალენდარში ექსპორტი
- D1-ში შენახული რვა თაიგული, 30%-იანი ფასნამატით
- შეკვეთის მოთხოვნა სერვერზე გადამოწმებული ფასით
- თანამშრომლის ხელით დადასტურების/მიტანის გვერდი და მიტანის შემდეგ თაიგულის სიცოცხლის მონიტორინგი
- მობილური და დესკტოპის ადაპტიური ქართული ინტერფეისი

## Cloudflare არქიტექტურა

Worker-ის კონფიგურაციაა `wrangler.jsonc`-ში. D1 binding-ის სახელია `DB`, მონაცემთა ბაზის სახელია `yvavilo-db`, ხოლო საწყისი სქემა და პროდუქტები ინახება `migrations/0001_initial.sql`-ში.

Cloudflare-ის build პარამეტრები:

- Build command: `npm run build`
- Deploy command: `npm run deploy`
- Root directory: `/`
- Node.js: 22 ან უფრო ახალი

ახალ D1 მონაცემთა ბაზაზე მიგრაციის გაშვება:

```sh
npx wrangler d1 migrations apply yvavilo-db --remote
```

## ლოკალური გაშვება

```sh
npm install
npx wrangler d1 migrations apply yvavilo-db --local
npm run build
npm run preview:worker
```

`npm run preview:worker` გაუშვებს სრულ Worker-ს ლოკალური D1 მონაცემთა ბაზით. ცალკე ტერმინალში:

```sh
npm run test:backend
```

ინტეგრაციის ტესტი ამოწმებს რეგისტრაციას, შესვლას, პაროლის შეცვლას, პროდუქტებს, ახლობლებს, თარიღებს, შეკვეთებს და ორი ანგარიშის მონაცემების გამიჯვნას. `npm test` ამოწმებს TypeScript-ს.

## თანამშრომლის წვდომა

ჯერ დარეგისტრირდით საიტზე. შემდეგ D1 Console-ში გაუშვით:

```sql
INSERT OR IGNORE INTO staff(user_id)
SELECT id FROM users WHERE email = 'owner@example.com';
```

ამ ანგარიშით `/operations` გვერდზე შესაძლებელი იქნება შეკვეთების ხელით დადასტურება, გაუქმება და მიტანილად მონიშვნა.

## რეალური საზღვრები

- შეკვეთა ამ ეტაპზე არის მოთხოვნა. რეალური გადახდა და კურიერის ავტომატური გამოძახება ჯერ არ არის ინტეგრირებული.
- პაროლის შეცვლა მუშაობს შესულ ანგარიშში. ელფოსტით პაროლის აღდგენა და ელფოსტის დადასტურება ჯერ არ არის ჩართული.
- შეხსენებები მუშაობს აპის შიგნით; ტელეფონის push შეტყობინებები ჯერ არ იგზავნება.
- პროფილის ფოტო ინახება D1-ში შეკუმშულ data URL-ად. ეს გამოდგება ადრეული ეტაპისთვის; მომხმარებლების ზრდასთან ერთად ფოტოები Cloudflare R2-ზე უნდა გადავიდეს.
